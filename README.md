# Планы разработки страниц портала

Переносимое приложение для Windows: планирование задач трёх сотрудников на Ганте, история правок, экспорт в PNG и редактируемый PPTX.

## Запуск готового приложения

1. Скопируйте **всю** папку `GanttPlanner-win32-x64` на компьютер или флешку.
2. Откройте `GanttPlanner.exe` внутри папки. Установка, сервер и интернет не требуются.
3. Нажмите **Создать проект** и сохраните файл `.ganttplan`. Имена сотрудников можно исправить через **Команда**.
4. Новый отчёт создавайте кнопкой **Новый план**: предыдущий план копируется, после чего задачи и даты можно менять независимо.
5. Переносите между компьютерами файл `.ganttplan` через флешку. Рядом с ним приложение хранит `.bak` — резервную копию предыдущего сохранения. Если основной файл повреждён, при открытии будет предложено восстановление из `.bak`.

Для сохранения проекта на другую флешку или в другую папку используйте **Сохранить как**. Если запись не удалась, оставьте приложение открытым и нажмите **Повторить** либо **Сохранить как**.

## Планирование

- Кнопка **+ Задача** и знак `+` у имени сотрудника открывают редактор. Полосы задач перетаскиваются по целым дням; края полос меняют дату начала и окончания.
- Переключатель **Только в периоде** скрывает строки задач, целиком находящихся вне показанных дат. Он включён по умолчанию; скрытые задачи остаются в плане и снова появятся при расширении диапазона или отключении переключателя.
- В поле состояния доступны «Ожидает», «В работе» и «Выполнена». Две задачи одного сотрудника могут занимать один и тот же день.
- Задачу без дат можно оставить в **Очереди**. В редакторе при необходимости укажите связанную задачу.
- «Текучка» автоматически добавляется на каждую неделю и показывается одной строкой у каждого сотрудника. Кнопка `+` в этой строке добавляет ещё один отрезок; каждый отрезок можно переместить, изменить или удалить отдельно.
- **История** хранит завершённые правки. Восстановление прежней версии создаёт новую запись и сохраняет возможность вернуться к более позднему состоянию.

## Экспорт

Нажмите **Экспорт**, проверьте диапазон дат и предпросмотр, затем выберите путь для PPTX. PNG сохранится рядом с ним с тем же именем. Если нужно несколько слайдов, PNG получат номера страниц. Полосы, подписи и даты в PPTX остаются отдельными элементами PowerPoint.

## Разработка

Требуются Node.js 24 и npm. После `npm ci` команды: `npm test`, `npm run typecheck`, `npm run build`, `npm run package:win`. Последняя создаёт переносимую папку в `release/`.

Проект работает локально и не требует учётной записи или облачного сервиса. Файл проекта не рассчитан на одновременное редактирование на двух компьютерах.
